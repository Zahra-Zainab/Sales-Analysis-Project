# Sales-Analysis-Project
This Power BI dashboard provides an interactive view of sales data to help understand revenue patterns, customer behavior, and market performance. With easy-to-use filters and clear visualizations, this report supports data-driven decisions for improving business strategy.

## 🚀 Key Insights & Features  

- **📈 Total Revenue & Quantity Sold** – Summarizes overall sales performance.  
- **🌍 Revenue by City** – Compares how different markets are performing.  
- **🏆 Top 5 Customers** – Identifies the highest contributing customers by revenue.  
- **👥 Customer Breakdown** – Visualizes sales share by each customer.  
- **📅 Monthly Revenue Trends** – Tracks changes in revenue across time.  
- **🔎 Date & Year Filters** – Enables dynamic filtering to explore specific time periods.

## 🛠️ Tools & Technologies  

- **Power BI Desktop** – For creating and exploring the dashboard.  
- **Excel/CSV Files** – Used as the primary data source.  

## 🧰 How to Use  

1. **Install Power BI Desktop** – [Download here](https://powerbi.microsoft.com/desktop).  
2. **Get the Files** – Clone the project using:  
   ```bash  
   git clone https://github.com/Zahra-Zainab/Sales-Analysis-Project.git
 
   ```  
3. **Open the Dashboard** – Launch `sales-analysis-dashboard.pbix` in Power BI.  
4. **Explore the Data** – Use slicers and visuals to uncover trends and insights.
